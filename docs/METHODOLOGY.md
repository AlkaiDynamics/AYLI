# Methodology and Evidence Controls

## Blindness codes

| Code | Type | Meaning |
|---|---|---|
| B0 | Open exploration | Discovery-generating; no blindness claim |
| B1 | Prediction-before-search | Structural prediction recorded before target lookup |
| B2 | Mapping-frozen | Mapping fixed before the result was observed |
| B3 | Target-blind | Corpus selected without knowing whether it contained the target |
| B4 | Member-withheld | General structure known; a member/value was withheld |
| B5 | Cross-carrier blind | Operator derived in one carrier and tested in another |
| B6 | Cross-cultural blind | Operator derived in one tradition and tested in historically remote material |
| B7 | Negative control | Similar-looking material expected not to map |
| B8 | Null subtraction | Arithmetic/combinatorial inevitability modeled first |
| B9 | Downstream checksum | Preservation test; no independence vote |
| B10 | Historical lineage | Tests transmission rather than convergence |
| B11 | Adversarial falsification | Search optimized to break the claim |
| B12 | Holdout prediction | Consequence registered and deliberately left unsearched |

Blindness codes describe test design. They do not by themselves establish historical or analytical independence.

## Evidence vector

Evidence is not compressed to one score:

`E = (H, S, P, F)`

- **H** — historical support
- **S** — structural novelty after null subtraction
- **P** — predictive specificity
- **F** — falsification leverage

## Independence vector

`I = (historical, textual, analytical, carrier, cultural)`

Two observations can be culturally remote yet mathematically inevitable. Two manuscripts can be textually separate yet descend from one source. Both facts must remain visible.

## Claim states

`PROPOSED, REGISTERED_PREDICTION, OBSERVED, SUPPORTED, INDEPENDENTLY_SUPPORTED, PROMOTED, STRONGLY_SUPPORTED, WITHHELD, RESIDUAL, DOWNGRADED, RECLASSIFIED, CORRECTED, PARTIAL_FAIL, FAILED, CONTRADICTED, SUPERSEDED`

## Immutable revision rule

A correction appends a new event and claim revision. It never mutates the historical claim into something that appears always to have been known.
