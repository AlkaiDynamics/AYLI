# Scale-Transform Atlas

Each file in `transforms/` is one typed transform table. The files are intentionally separate so that equal numbers cannot silently collapse distinct operators.

## Standard visible cells

| Sequence | Local identity | Core function | Parent/source | Successor identity | Inherited function | Changed function | Hierarchy/relation | Outlier | Residual | Evidence |
|---|---|---|---|---|---|---|---|---|---|---|

The normalized backing fields additionally preserve source layer, orientation, address, carrier, transmission, and claim/event identifiers.

Outliers are unlimited in storage. A display may surface a small number, but mediators, containers, withheld members, remnants, return states, and failed controls remain separate records.
